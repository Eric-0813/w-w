# 持仓输入与计算口径

本工具用 Python 3.9 或更新版本的标准库计算用户提供的快照，不需要 API 密钥。适用于每单位价值可直接按数量乘价格计算的股票、基金份额等多头持仓。空头、期权、期货、债券应计利息和其他需要乘数或特殊估值规则的资产不在脚本范围内。

## CSV 字段

文件使用 UTF-8，可带 BOM；首行使用以下列名，数值中不含货币符号或千位分隔符。

| 列名 | 含义与要求 |
| --- | --- |
| `symbol` | 明确的证券标识；有歧义时包含交易所或股类。不能为空。 |
| `quantity` | 持仓单位数量，非负有限十进制数。支持零和小数份额。 |
| `price` | 每单位价格，以 `currency` 计价；非负有限十进制数。非零持仓的零价格会产生警告。 |
| `currency` | 三位大写的主单位币种代码，如 `USD`、`AUD`；脚本不自动改大小写，也不验证完整 ISO 币种名录。便士等次单位报价须先换算成主单位。 |
| `price_as_of` | 价格时间，ISO 8601，必须包含 `Z` 或时区偏移，如 `2026-11-10T21:00:00Z`。 |
| `fx_to_base` | 1 单位报价币种可换取的基准币种数量；外币必须填正数，基准币种可留空或填 `1`。 |

六列都必须存在，可调整顺序，不接受额外或重复列名。同一 `symbol` 与 `currency` 组合不能重复；若来自多个账户或批次，先核对价格和汇率，再明确合并数量，避免静默重复计入。不要将未提供的现金、负债或其他账户假定为零。

`--base-currency` 也遵守大写主单位规则。`GBp`、`GBX` 等次单位表示不能直接改名为 `GBP`；需要先核实数据商单位并换算价格。例：250 便士应输入 `price=2.50,currency=GBP`，再配合 GBP 到基准币种的汇率。脚本拒绝混合大小写，以及 `GBX`、`ZAC`、`ILA` 别名；这不是所有数据商单位的完整清单。数据商可能用大小写区分主/次单位，参见 [LSEG 的单位说明](https://community.developers.lseg.com/discussion/25823/how-to-tell-that-a-quote-is-in-pennies)。

## 运行

在技能目录中运行：

```bash
python3 scripts/portfolio_snapshot.py assets/portfolio.example.csv --base-currency USD --as-of 2026-11-12T00:00:00Z
```

示例 CSV 为虚构持仓及固定日期，不能用于获取当前行情。实际分析将输入路径替换为用户的 CSV。

`--base-currency` 必填。省略 `--as-of` 时使用运行时的当前时间；为了复现结果，建议提供带时区的截止时间。脚本拒绝相对于该截止时间来自未来的价格。

`--max-age-days` 默认为 `3`，超过阈值的价格会产生警告；这是经过时间的检查，不识别交易日、节假日或市场是否开盘。可以按问题显式设置阈值，不能仅为隐藏警告而修改。

成功时，标准输出为 JSON；错误写入标准错误并返回非零退出码，不输出部分估值。金额、数量、价格和比例使用十进制字符串，避免二进制浮点显示误差；显示时再按用途取舍小数位。

输出包含 `total_value_base`、`positions`、`quote_currency_exposure` 和 `warnings`。持仓与币种分组中的 `value_base` 是基准币种市值，`weight_pct` 是百分数（`"40"` 表示 40%，不是 0.4）。百分数以四舍六入五成双规则保留最多 8 位小数，显示占比之和可能有微小舍入差异。

估值运算支持 50 位有效数字，若必须舍入才能继续则报错。单个非零数的数量级限制为十进制指数 -100 至 100。脚本不会为了接受异常数据而静默截断精度。

## 计算与解释

```text
单项基准币种市值 = quantity × price × fx_to_base
输入持仓总市值 = 所有单项基准币种市值之和
单项权重 = 单项基准币种市值 ÷ 输入持仓总市值
报价币种敞口 = 同一报价币种各项的基准币种市值之和
```

总市值为零时权重为 `null`，不能解释为每项占比零。不同价格时点或同币种使用不同汇率时会产生警告，应在报告中说明该结果并非严格同步估值。

CSV 未包含汇率时间戳，脚本不能验证汇率的新鲜度。应另行记录汇率来源和时间，特别注意汇率方向；例：若 1 AUD = 0.65 USD，USD 基准下的 AUD 行填 `0.65`。报价币种敞口只按报价币种分组，并不代表发行人收入币种或汇率敏感度。

这份结果只覆盖输入的持仓，不一定等于完整账户净值。它不包含交易成本、税、融资、历史成本、现金流或收益率计算；不要从快照推导投资表现。将过期、缺失或异常数据的影响随结果一起交代。
